# 工安智瞳：铸钢工作台

首页与 GIS 使用相同的左侧分组和固定场景 / 右侧功能面板。顶部只保留品牌、数据刷新及当前账号菜单。

| 左侧分组 | 保留的功能 |
| --- | --- |
| 总览 | 工区目录、我的待办、首页 / GIS 切换 |
| 现场监测 | 人员、设备、区域、报警、移动演示 |
| 协同处置 | 异常助手与业务依据、影响链、作业冲突、工单、历史回放、能耗 |
| 项目管理 | 图层与布局、GIS 观测导入、来源与配准、联动数据源、账号与工程审阅 |

点击组名展开；点击子项切换右侧内容。场景常驻，定位保留当前筛选与列表滚动位置。右下方显示对象详情；“返回上一镜头”恢复首页定位前的镜头。右侧可收起，点击场景右边“列表”重新展开。原工区台账五项统计收纳于“图层与显示”。

首次从登录页进入后，所有核查、指派和复核使用顶部同一账号。点击头像菜单打开个人资料、账号管理、工程审阅、备份、操作历史等；“切换账号”退出当前会话。页面不再重复设置第二套登录。

3D 保留原厂区边界、建筑投影、A/B 框架及高度配置；补充屋面接缝、立面窗带、结构饰条、屋面机组、金属与混凝土材质、环境反射和阴影。这些细节属于设计假设，不新增工程连接或实测依据。实际渲染来自可旋转、可选择、可巡视的 Three.js 模型；概念设计图的照片级细节不是现场模型精度。

“精细材质 / 轻量显示”可降低首页阴影与装饰细节的显示负担。“动效开启 / 关闭”控制齿轮、字标与定位反馈，并尊重系统减少动态效果设置。卫星影像仍需要网络，平面和 3D 使用本地资源。

验证：50 项现有前端测试通过；25 项本地浏览器验收通过，包括刷新、筛选定位保留、键盘巡视、助手真实工具查询、五项分析导航、模拟启停、GIS 观测导入、测距、移动布局及减少动态效果。原始边界和厂区配置文件未更改。
