# 清爽空间视图与厂区整体剖面

更新时间：2026-10-07。

首页 `http://127.0.0.1:8080/` 和遥感工作台 `http://127.0.0.1:8080/workbench.html` 同步使用一套外部厂区与内部剖面模型。

| 视图 | 保留内容 | 标识策略 |
| --- | --- | --- |
| 卫星影像 | 官方影像与厂区边界 | 不显示人员、设备、危险区点位 |
| 厂区平面 | 建筑、合并道路面、空地、边界、A/B 名称 | 不显示业务编号点位 |
| 三维外观 | 建筑屋顶与体量、道路、围栏 | 不显示业务对象或编号点位 |
| 厂区整体剖面 | A/B 两个工区同时剖开，保留配套建筑 | 仅显示两个工区名称卡片，并自动避让 |
| 局部 A / B | 设备、人物、危险范围、监测详情 | 保留巡检悬浮标识与进入报警 |

A 区采用西侧厂房轮廓，高跨钢结构、冲压与数控加工、机器人、输送线及桥式起重机组成装配车间。B 区采用东侧不规则厂房轮廓，高压与变压器布置于主厅，阀门与仪表位于独立操作范围，泵组与稳压装置位于另一设备带，侧翼布置监控操作台、UPS 电源及巡检人员。B 区新增换热、备用柴油发电、双机压缩、水处理和 UPS 五组设备，共 12 组设备、8 位人员和 7 个危险区域，详见 [B 区重建说明](factory-power-v9.md)。设备、人物和危险区的几何边界经过厂房包含关系检查。

两个页面分别订阅同一工厂后台；GIS 嵌入的 A/B 巡检页由父页面转发观测。隐藏标识不停止位置采样、监测或报警。布局迁移保留接口上报位置、测量及事件，更新演示设备布局与初始位置。

## 布局数据与维护

- 原始参考：`frontend/assets/factory/reference-site.geojson`，保留公开厂区与卫星近似描绘轮廓。
- 显示布局：`frontend/assets/factory/factory-plan.geojson`，道路缓冲面合并，扣除建筑缓冲，空地避让建筑及道路，周边范围收紧。
- 内部底面：`frontend/factory-footprints.mjs`，从原始厂房轮廓与参考变换反算。局部 A/B 与整体剖面复用同一建模函数。
- 场景组合：`frontend/factory-site-model.mjs`，统一外观与整体剖面。
- 后台目录：`gis/factory-catalog.json`，布局修订号为 3。

变更原始轮廓或参考变换后，可运行 `python scripts/build_factory_layout.py` 重新生成显示布局与内部底面。变更模型设备、人员、危险区域或轨迹后，运行 `node scripts/export_factory_catalog.cjs` 生成目录；需要迁移已保存布局时增加目录修订号，再运行后端与前端测试。

公开轮廓沿用 OpenStreetMap contributors / ODbL 署名；官方影像保留 Esri 等来源及采集日期。厂房高度、工艺、内部设备与运行状态为演示设计，没有现场测绘或现场传感器接入。
