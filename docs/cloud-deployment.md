## 免费试跑

仓库根目录的 render.yaml 明确选择免费实例、关闭自动更新，不创建付费磁盘。注册并登录 https://dashboard.render.com 后连接 GitHub 仓库，确认 main 已包含本轮部署文件，再创建 Blueprint。

也可手动创建 Web Service：选择 main、Docker，Dockerfile 路径 ./Dockerfile，选择 Free，健康检查 /health。不要选择 Static Site；本项目需要 Python 后台。平台分配 PORT，启动命令由 Dockerfile 提供。

免费服务空闲 15 分钟休眠，唤醒约需 1 分钟；重启、更新或休眠会丢失本地 SQLite 新记录。默认重建模拟数据，适合体验功能，不适合保存参赛实验原始记录。具体以 https://render.com/docs/free 为准。

## 正式评审与数据保留

先试跑并观察内存、响应与并发，再选择足够资源的付费实例。需要保留数据库时挂载持久磁盘并把 DATA_DIR 指向挂载目录。云盘挂载后需验证 appuser 对目录可写；不要只确认网页打开就认为存储生效。只开一个应用实例，避免多个后台实例写不同 SQLite 数据文件。

价格核对日 2026-10-11：512MB 实例 7 美元/月，2GB 实例 25 美元/月，磁盘 0.25 美元/GB/月；流量等超额费用和最终账单以平台为准。免费配置不会自动升级。https://render.com/pricing

无需先买独立域名，使用平台提供的网址。评审提交时同时准备可运行源码包和不超过 2 分钟的 MP4 视频。

## 演示身份与范围

此版本是公开共享的模拟实例，演示账号可操作模拟工单；不能上传个人真实信息、现场秘密或工程控制凭据。DEMO_MODE=1 和 FACTORY_ANALYSIS_DEMO=1 已明确设置，不需要为 B-05 规则与工具流程填写模型 API 密钥。演示账号及流程见 device-investigation-v19.md。

PUBLIC_READ_ONLY=1 会拒绝所有写入请求，包括登录，因此此选项仅用于展示只读模型；交互评审保持 0。PUBLIC_ORIGIN 可设置为实际 HTTPS 地址，限制其他网页来源调用。接口工具不携带 Origin 时仍需经过后台账号检查；这不是账号权限的替代品。

当前网关支持项目主页面所用的 HTTP 查询与提交；旧版独立 WebSocket 端点和流式响应尚未接入公网入口。不得把这些旧端点列入此版本上线验收范围。

## 发布后的验收

1. 用手机流量或另一台电脑，关闭本机服务，打开公网首页和 /workbench.html。
2. /health 返回 200，页面请求均访问公网 /api 路径，没有访问 127.0.0.1 的后台。
3. 安全员登录 → 查询 B-05 → 检查观测来源和时间 → 草案确认 → 维修员提交凭证 → 另一复核员关闭；无权限操作仍被拒绝。
4. 对当前实例执行重启并核对工单、履历和实验记录是否按所选免费/持久存储模式保留。正式评审须验证记录保留。
5. 检查浏览器模型加载、GIS、响应时间和多人同时使用；确认评委所在网络能直接访问。

只能在这几项通过后，把实际公网地址填写进参赛说明文档。不能把本机预览地址作为评委可访问的 Demo 链接。
