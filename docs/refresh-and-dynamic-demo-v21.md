# 两页联动刷新与动态演示（2026-10-12）

首页“刷新数据”和 GIS“刷新观测”现在统一刷新空间观测/列表/区域告警、设备核查依据以及影响链、计划、工单和能耗。按钮在请求期间禁用，页面显示完成时间、读取的观测版本及模块；部分失败与全部失败分开显示，可恢复后重试。刷新自动返回实时视图；不会生成新传感器读数，也不会创建工单。新数据来自后台模拟采样或账号导入。

各空间视图共用同一个只读状态请求；首页与 GIS 均拒绝较旧的延迟状态回滚。分析和核查接口各自读取最新证据，因此其查询版本可能高于空间状态，界面保留各自版本。刷新保留未提交的计划、台账和工单输入。

验证：前端共 43 项检查通过，包括新增 5 项共享刷新、重复点击合并、部分失败、断流恢复和无效状态检查，以及 2 项实时按钮身份与回调检查。隔离浏览器在两页验证刷新实际请求、没有 POST 写入、模拟 503 断流及恢复，并检查刷新期间保留工单和区域索引按钮；无需真实设备或模型密钥。

动态视频使用独立本地 Playwright 浏览器和隔离模拟数据库录制实际鼠标点击、页面滚动、模型和后台响应。只添加鼠标位置/点击圈与后期字幕，未使用静态截图代替操作。公开视频内容仍为原型，不把演示闭环时长作为提效实验结果。
