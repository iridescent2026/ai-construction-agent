# 工区连接与支撑细化

2026-10-07。首页与遥感工作台的局部 A、局部 B 和整体剖面共用本次改动。

## B 动力区

- 三路主管连成主厅与侧墙管廊；增加连续横梁、斜撑、抱箍、底板与锚栓，闲置管口使用盲法兰。
- 两排电缆桥架采用落地支架、托臂与斜撑，电缆落入接线箱。原本悬空的桥架获得支撑。
- 供回水及压缩空气支路接到阀门组、循环泵、稳压罐、换热机、压缩机和水处理设备接口；高位支路增加立柱和支承。
- 阀门按原始网格的两端法兰轴线定位，径向比例一致；泵组阀门旋转到对应管道方向，消除手轮偏置导致的接口错位。
- 修正泵与电机的联轴器方向，补充电机脚架、表盘引压管、变压器散热片连接及储油柜支座、开关柜母线绝缘支撑、发电机排气汇管及支座。
- 稳压罐平台增加腿柱、连通的小平台与贴合平台高度的爬梯。监控屏、操作台显示器补齐支撑架；通风格栅贴合实际后墙。

## A 装配区

屋架与钢柱位置统一，补充纵向梁、连接板、斜撑。灯具通过吊杆挂在灯轨上，灯轨连接屋架；电缆桥架通过吊杆、横担连接屋架。修正起重机斜撑、输送机护栏连接、数控设备信号灯底座与离地托盘。

## 验证与维护

63 项后端测试和 28 项前端测试通过，包含设备间距、通行带、厂房边界、目录与编号一致性、导入阀门实际端口位置，以及逐一展开实例化网格的连接检查。实体零件须通过接触链连接到地面；业务图标及危险区透明覆盖层不计入实体检查。此检查用包围盒和 4.5 cm 接缝容差发现明显断开，另通过浏览器旋转模型观察接头与支架。

设备、人员、危险区编号和目录修订号保持不变；后台观测、详情与进入 / 离开报警继续同步。
