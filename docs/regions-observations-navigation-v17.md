# V17 区域、人员定位、导入与功能导航

## 区域和人员对应

GIS 卫星与平面常驻显示 Z001 土方施工区、Z002 吊装作业区。标签避让并用细线指向对应范围；三维外观同样显示区域编号和名称。左侧区域索引、告警和地图同源。点击告警同时显示该人员和对应区域，图层隐藏时自动打开相关图层。

首页全景现在实际渲染室外人员与授权移动设备。人员管理“定位”切换对应工区、聚焦实际观测坐标、高亮编号并显示来源及采集时间；右侧索引补室外人员、车辆和区域。该位置是后台当前演示或接口坐标，尚非实测 GPS。恢复视角返回全场。

## 导入观测

1. GIS 左侧展开“数据接入与核验”。
2. 点击“示例：进入土方区”，编辑框自动填写以下 JSON；此时尚未上报。
3. 点击“导入观测”，导入结果显示具体编号、坐标、区域编号和名称，地图聚焦 P023，Z001 产生进入告警。
4. 点击“示例：离开危险区”，再点击导入；P023 更新到 x=-41,z=12，退出告警。

```json
{"observations":[{"id":"P023","x":-28,"z":23}]}
```

也可粘贴自有 JSON 或选择小于 200 KB 的 JSON 文件。文件仅填写编辑框，仍须点击导入。编号必须已经存在，一批最多 100 条，重复编号、缺一个坐标、非法格式或单位会被拒绝，整批校验后才提交。

设备示例：点击“示例：泵组温度”，再导入，会更新 B-05 的读数；设备详情/分析影响链读取同一后台数据。B-05 是 B 区固定泵组，不在 GIS 室外人员图上；固定设备不能上报 x/z。

```json
{"observations":[{"id":"B-05","measurements":{"temperature":{"value":65,"unit":"℃"}}}]}
```

接口 `POST /factory/observations`；可填写带时区 `observedAt`，省略则使用后台接收时间。位置 x/z 为场景局部米制坐标，不是经纬度；GIS 参考底座额外进行旋转和比例变换，尚未实测配准。手动 JSON 是测试数据，接口接收不等于真实 GPS/传感器来源。超过 120 秒的定位转为未知。

手动上报会停止包含该人员的演示轨迹（三人组合整组停止）；接口位置受到保护，不会被重置演示或重新启动模拟覆盖。想让该对象继续移动需要连续上报新位置，也可选择其他演示对象。回放状态禁止导入，须先返回实时。

## 分析与闭环怎么操作

首页与 GIS 的左侧保留“分析与闭环”导航，按用户要求移除两页顶部的同名下拉入口，可以直达五个标签页。各页有具体操作提示。

- 设备影响链：选 B-05 → 查询 → 高亮 → 按需要发起复核工单。候选管线须核对图纸。
- 作业冲突：查看已有演示冲突，或填写示例 → 保存并检查。
- 险情回放：读取记录 → 拖动时间轴 → 返回实时。仅显示程序实际记录的历史。
- 维修闭环：选择工单 → 指派 → 被指派人开始处理 → 提交凭证 → 另一人复核关闭。
- 能耗分析：联动模拟每 5 秒采样；也可填写演示电表 → 导入。相邻有效读数形成积分估算。

## Not Found 的含义与启动

`/factory/analysis` 返回 404 表示当前连接的后台没有这项接口，常见于新版前端连接旧后端，刷新页面不能更新运行中的后端。页面会显示连接的 GIS 地址与启动建议；模拟按钮在初次连接成功前禁用。

运行同一源码目录的 `run_demo.py` 同时启动前后端，自动生成端口一致的 `config.js`。本次验证用的预览为首页 http://127.0.0.1:48080/、GIS http://127.0.0.1:48080/workbench.html；GIS API 为 http://127.0.0.1:48000。默认直接启动且无端口偏移时为 8080/8000。
