# 业务与工程依据审阅清单

拟定场景为“建筑施工或模块化生产的辅助排水设备异常核查”。B-05 的设备用途、实际机型及岗位职责尚未由企业或工程老师确认；名称和模型不能证明这是一套真实安装的泵组。

公开资料可帮助列出要询问的字段，不能直接赋予 B-05 工程阈值。已查阅 [Grundfos NBS 安装与操作手册](https://www.grundfos.com/content/dam/local/en-us/campaign-files/99932034_022021_NBS_IO_EN_US_Online%20_1.pdf)（文件编号99932034，022021版）：第2.3节提供铭牌识别字段，第7.6节涉及监测基准，第8.2节列维护内容，第10节列故障检查，第11节给出该产品的技术数据。它是特定型号的参考，不证明 B-05 型号或参数。可按[厂家官方检索说明](https://www.grundfos.com/solutions/support/how-to-guides/how-to-find-installation-and-operation-manuals-online)查找实际型号的手册。

## 请工程老师审阅的五件事

| 项目 | 需取得的实际依据 | 当前状态 |
| --- | --- | --- |
| 设备与建筑业务关系 | 用途、介质、服务范围、实际铭牌或场景意见 | 设计假设 |
| 连接关系 | 图号、版本、页码、供电/介质/控制类型、方向、隔离状态 | 候选台账 |
| 观测和规则 | 测点、单位、适用工况、文件限值、测量误差、有效期 | 待核验；60℃仅软件测试 |
| 人员与检修协调 | 岗位职责、许可流程、位置有效性、吊装/通行范围 | 演示配置 |
| 完工和复核 | 凭证要求、独立复核人、退回条件及告警解除条件 | 原型流程 |

## 审阅记录模板

审阅日期：待填写；审阅者姓名/岗位：待填写；资质或职责声明：待填写。

材料编号、版本、页码：待填写。结论请选择“无法核验 / 需要修订 / 材料内容已审阅确认”，逐项写明理由、适用范围和仍缺的证据。不同意见均保留，不要求老师为原型安全性背书。

用真实独立复核账号在账号中心“工程依据审阅”填写上述记录。系统只保存责任人声明和文档引用，不能核实资质或附件真伪；演示账号审阅仅标为原型审阅。不把公开通用手册或一次课堂交流称为企业现场试点。
