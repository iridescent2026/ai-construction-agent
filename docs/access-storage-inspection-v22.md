# V22：登录、项目留存与 A/B 巡视

本轮将页面入口改为先登录，再查看个人待办、观测和工单。首页与 GIS 共用同一会话、头像样式和账号中心，沿用铸钢品牌、机械框和螺钉。

## 使用路径

1. 打开首页自动进入登录页。展开“演示岗位账号”，填入安全员账号并登录；系统为本浏览器建立独立模拟空间。正式项目账号须勾选对应选项。
2. 首页“我的待办”列出待处理、待复核工单和区域告警；点工单直接打开维修闭环。两页刷新按钮统一读取观测、核查、计划、工单及个人待办，不会凭空生成新读数。
3. 安全员核查 B-05 → 检查来源、时间和规则 → 查询候选影响、人员与作业 → 准备草案 → 人工确认并指派。
4. 切换为维修账号处理并提交凭证，再由另一复核账号关闭或退回。换角色保留同一个演示空间；新建空间才隔离数据。处理人不能复核自己的处理结果。
5. 账号中心可修改姓名、部门、三种头像样式及密码。管理员可创建本项目账号、设置岗位和停用；变更权限或密码撤销旧会话。管理员不能停用或降低自己的权限。
6. 首页 A/B 视图点击“进入 A/B 巡视”：WASD/方向键移动，拖动画面观察，手机用方向按钮，Esc/“退出巡视”返回。巡视有边界和模型碰撞限制；移动的是观察相机，不产生人员定位、巡检凭证或现场到达记录。

演示安全员/维修员/复核员/只读员沿用既有示例密码。新增个人空间管理员 `demo-admin / AdminDemo!2026`，只对其所属个人空间有效。正式管理员为 `project-admin`，密码由部署者通过私密配置设置，不能将其写入仓库。

## P0：访问、隔离与数据保留

- 公网默认 `DEMO_WORKSPACES_REQUIRED=1`。所有业务读写经过账号检查；模拟启停仅安全员/管理员允许。公开旧接口的写操作被网关阻止。
- `X-Demo-Workspace` 携带随机空间凭据，服务器只保存其摘要，24 小时有效；工单、账号、规则与实验分空间存储。另一空间的登录令牌不能使用。空间过期后停止采样；历史数据库不自动销毁。最多 20 个同时有效空间、40 个保留空间，并限制创建频率。达到上限需管理员归档，不能宣称无限访客服务。
- 设置 `DATABASE_URL` 后，工厂状态、账号、会话、工单、业务台账、读数、实验与空间索引使用外部 PostgreSQL。表位于服务端私有 schema，不使用 Supabase 公共 Data API；数据库连接串只供服务器使用。
- 未配置时仍使用 SQLite；Render 免费容器不保存新增本地记录。外部数据库“已配置”不等于“已验证”。管理员账号中心的留存核验保存一个编号；重启服务后再次点击，必须读到原编号且显示跨进程留存，才能确认验收。
- 业务 JSON 备份不包含密码和会话，客户端恢复上限 3.5 MB；恢复前保存当前业务备份。恢复不把旧位置/读数伪装成新观测，不恢复身份；导入确认连接降为待审阅，导入实验不计新完成的人机对比效果。JSON 校验只检查完整性，不能证明材料真实性。完整灾难恢复还须由数据库管理员备份账号、私有 schema 和附件，不能只依赖业务导出。

## P1：依据、语言、实验和空间

- 工程依据审阅支持设备用途、连接台账、适用规则、坐标配准和责任岗位五项，记录材料页码、版本、审阅账号、资质声明及意见。仅正式项目最近一次确认审阅减少待核验项；演示空间的任何账号都只能作原型审阅。系统不能自动认证资质或文件。
- 作业范围支持矩形、多边形和带宽度的轨迹扫掠；时段交集同时检查已填写的高度区间。只填楼层名称不能排除冲突，高度未知保留潜在冲突。候选检修范围必须包含设备位置。输入仍为原型坐标，未经现场测绘或许可审批。
- 助手支持一问多项、常用同义词、否定派工和缺失条件追问。配置真实模型时只用模型分类意图；观测、依据、建议和操作权限继续由实际后台工具产生。模型失败有真实回退记录，不声称执行了未执行工具；聊天只准备草案，不自动批准或关闭。
- 模型只发送用户问题用于分类，不附带观测台账。不要在公开演示里输入真实个人信息或工程秘密；正式使用须核对供应商与数据授权。每空间每分钟最多 6 次、每进程 UTC 日默认 100 次；进程重启会重置计数，这不是模型账户账单硬上限。计费由已配置 API 账户承担。
- 原型实验支持独立账号、本人答题声明、背景和轮换顺序建议。管理员汇总四题两种方法的正确配对、真实服务端计时。练习和演示账号不计业务效果；至少三人完整配对后才满足原型比较的最低数据要求，仍须监督、核对身份和试验设计，不能外推企业收益。

## Render + Supabase 配置

保留 Free Docker、新加坡、一个应用实例。现有服务自动部署关闭，需要手动发布 GitHub main。Supabase 使用免费项目的 **Session pooler** 连接串（端口 5432）；密码含特殊字符时按 URL 编码，不启用付费 IPv4 插件。

在 Render Environment 设置，密码/密钥只能进入私密字段：

| 变量 | 值 |
| --- | --- |
| DATABASE_URL | Supabase Session pooler 完整 PostgreSQL 连接串 |
| FACTORY_ADMIN_PASSWORD | 自设至少 12 位密码，仅用于首次建立 project-admin；后续改密不被重新覆盖 |
| WORKFLOW_MODEL_ENABLED | 1 开启真实意图分类；0 仅本地词典工具 |
| WORKFLOW_MODEL_API_KEY | 已有服务的私密密钥 |
| WORKFLOW_MODEL_BASE_URL | DeepSeek 为 https://api.deepseek.com；兼容服务使用实际 HTTPS 地址 |
| WORKFLOW_MODEL_NAME | DeepSeek 为 deepseek-chat；兼容服务使用实际模型名 |
| WORKFLOW_MODEL_DAILY_LIMIT | 可选，默认 100；0 禁止外部模型调用 |

启动失败时检查密码编码、连接池地址、依赖构建和数据库配额；不要退回临时数据库并声称已持久保存。须逐项验证登录、读写、刷新、角色隔离、模型成功/回退与重启留存。免费服务休眠及网络可达性依旧需要评审前检查，并准备源码包和视频备选。
