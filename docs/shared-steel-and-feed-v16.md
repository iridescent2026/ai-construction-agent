# 铸钢品牌与五项联动数据 V16

## 两页共用样式

首页与 GIS 使用同一 `steel-system.css`、`industrial-themes.mjs`。钢框厚度为 6 px，内外双层钢边、统一拉丝纹理和投影；每个结构面板固定四个 18 px 内六角螺钉（手机 16 px）。旧 GIS 的字符螺钉、旧首页螺钉和旧分析模块螺钉已替换，避免同时存在不同尺寸和重复装饰。

“工安智瞳”采用已选第一款铸钢铭文：倾斜字形、银色切面、逐层金属阴影。保留原 Logo 图形，通过原 PNG 的背景定位显示图标，不改原资产。两页品牌结构相同：桌面组合宽 324 px，图形 62 × 77 px，四字字号 48 px；手机组合宽 264 px，图形 50 × 62 px，字号 39 px。英文小字、字距和图文间隔共用规则。手机导航折行，首页功能轨不占用正文流，顶端位置根据实际页头高度计算。

## 启动即有数据

`python run_demo.py` 默认将 `FACTORY_ANALYSIS_DEMO=1` 传给后台。本地演示启动后，不用手工粘贴 JSON 即可查看：

| 功能 | 联动来源 |
| --- | --- |
| 设备影响链 | 既有候选连接台账 + B-05 泵组温升模拟 + 关联人员和待处理工单；读数与工单每 5 秒刷新 |
| 作业冲突 | 室外吊装隔离范围与临时人员通道，当前时段重叠；均标为演示计划 |
| 险情回放 | P023 / P024 / P021 三人巡检产生的真实程序运行记录，每秒保存；非真实现场轨迹 |
| 维修闭环 | 一张标为演示的 B-05 工单，指派“演示维修员”，仍需用户手动开始、填写凭证、另一人复核 |
| 能耗与待机 | B-05、B-01、A-01 后台模拟 kW，每 5 秒采样；按运行状态估算待机，A-01 附带模拟新增产量 |

演示初次启动生成三组带 demo 标记的初始化电表样本（前 60 秒、前 30 秒、当前），用于立即展示积分；它们是构造的样本，不是此前实际采集的历史。已有近期有效记录时，恢复采样仅增加当前记录。连续采样通道为 `live-demo`，手动电表示例为 `manual-demo-example`，接口默认 `primary`；设备、来源、通道、班次分别计算，避免多通道交错或班次切换错误地桥接读数。

两页的“联动模拟数据源”控制台共用同一后台，可以启动和停止；状态显示最近采样时间、采样组数与异常。停止后历史工单、电表和回放保留，模拟温升恢复普通演示读数。用户自行启动的其他轨迹不会被联动停止误停。工单不会自动完工或冒充人工复核。关闭工单不会自动清除空间告警。

## 保护已有数据

- 已有接口定位的人员不被轨迹覆盖；已有接口读数的设备不被温升或电表模拟覆盖。采样过程中转为接口读数的设备也被跳过。
- 既有连接台账不重写。演示计划只更新自己的两个 demo 编号，保留人工计划；人工计划若使用同名编号也不覆盖。
- 已有未关闭的演示泵组工单不重复创建；人工工单不改动。
- 只清理本生产器登记拥有的最近电表记录，最多保留约 1800 条（一般约 50 分钟，取决于设备数）；手工或接口记录不会因为编号前缀相同而被删除。
- `DEMO_MODE=0` 禁止联动模拟、演示电表、演示计划和演示工单。设置 `FACTORY_ANALYSIS_DEMO=0` 可关闭启动时自动演示，仍保留手动控制。
- 自动演示初始化失败不妨碍服务启动，错误在分析控制台显示。模拟不能证明该公开参考厂区的真实设施、设备连接或运行状态。

## 新接口与采集通道

`POST /factory/analysis/demo-feed`：`{"action":"start"}` 或 `{"action":"stop"}`。状态在 `GET /factory/analysis` 的 `demoFeed` 中返回。真实数据入口沿用 `/factory/observations`、`/factory/analysis/meters`、`/factory/analysis/graph`、`/factory/analysis/plans`。

电表增加可选字段 `streamId`（默认 primary），应稳定对应同一独立采集通道。不同通道的结果不会自动相加。相同设备、来源、通道、采集时刻只允许同一记录编号；重复编号同内容幂等，内容不同拒绝。旧记录缺少 streamId 时视为 primary。

```json
{"readings":[{"id":"meter-live-001","deviceId":"B-05","source":"telemetry","streamId":"meter-b05-main","observedAt":"2026-10-07T10:00:00+08:00","powerKW":6.2,"running":true,"shift":"白班","productionDelta":null}]}
```

示例时间需替换为真正采集时间。source=telemetry 只是采集方的来源声明，不能证明真实设备身份。当前未获得现场 GPS、摄像头、电表或工程台账；这些演示不能写进比赛材料作为实际节能、降本或安全效果。

84 项后端测试、32 项前端测试通过；电表通道修正后相关 15 项再次通过。Chrome 验证两页桌面和手机的品牌尺寸、字体、钢框背景/投影、螺钉样式参数完全一致；检查三台设备持续采样、计划冲突、手动工单全流程、禁止自审、回放不被轮询覆盖、返回实时和联动启停。页面截图也检查实际排版，避免导航进入正常布局流造成留白。

运行工作区 outputs/启动GIS改进版.cmd 前，先 Ctrl+C 停止同端口旧服务。新版首页 `http://127.0.0.1:48080/`，GIS `http://127.0.0.1:48080/workbench.html`；页面 Ctrl+F5 刷新不等于重启后端。源码未推送远端，也未改变 GitHub 分支。详细的五项分析流程仍见 [V15 功能接口说明](factory-analysis-v15.md)。
