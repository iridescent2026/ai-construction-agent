# 工安智瞳 · 数字孪生首页与实时联动

本地首页：http://127.0.0.1:8080/

GIS 工作台：http://127.0.0.1:8080/workbench.html

首页采用参考图的机械面板风格：保留原版 logo 与施工背景，使用深色拉丝质感、银灰厚边框、四角螺栓及黄色选中状态。左侧设备、人员、危险区、报警和图层面板可打开、收起、调宽；场景高度也可调整。

数字孪生首页直接提供纯厂区外观、整体剖面、A 装配工区和 B 动力工区；遥感工作台同时提供卫星影像与厂区平面。两个页面使用 `factory-site-model.mjs` 的同一套外观与剖面，平面道路经过合并并避让建筑。卫星、平面与封闭外观不显示业务标识点，整体剖面仅显示 A/B 两个工区名称。A/B 巡检视图保留人员、危险设备标识和悬浮详情。

内部底面从外部厂房轮廓反算，B 区设备按动力主厅与控制侧翼重新布置。GIS 的 A/B 内部视图由父页面推送同一份观测；整体剖面直接订阅父页面数据，避免独立采样造成版本差异。升级布局时后台更新演示初始位置，保留接口上报的定位、测量和事件记录。公开厂区及模型仍属于布局参考，工艺、人员、危险区与报警为演示配置，尚未现场测绘配准。见[视图说明](factory-clear-views.md)与[卫星图参考说明](satellite-reference.md)。

## 已联动的数据

- 30 台设备、26 位人员、12 个危险区域。
- 后台每秒采样；页面每次请求完成后约一秒再请求，不叠加并发请求。
- 按设备类型显示温度、压力、电压、电流、漏电或负荷等演示测量。
- 人员和未授权车辆进入危险区产生报警，离开自动解除并保留记录。授权土方区挖掘机和固定设备不会误报为进入。
- 两个页面共享后台演示轨迹；关闭页面不会让后台轨迹状态与其他页面分叉。
- 断连显示未知并保留最后模型；服务恢复后自动重连。定位超过 120 秒没有更新时显示未知，已有危险区记录保留待核验，不伪造离开事件。
- 通过接口上报的位置、测量值持久保存；演示采样和恢复初始位置不会覆盖接口上报的数据。

## 现场数据接入

目前已接通本地实时后台，尚未收到现场定位系统或传感器接口地址。页面清楚标注后台演示数据；演示读数不作为设备安全判断，设备报警阈值需要按现场设备配置。

读接口：`GET http://127.0.0.1:8000/factory/state`，包含 revision、updatedAt、entities、active、events、demo、coordinateSystem。

写接口：`POST http://127.0.0.1:8000/factory/observations`，请求头 `Content-Type: application/json`。示例仅供接入说明，不会自动上报到当前运行场景：

```json
{
  "observations": [
    {"id": "P023", "x": -28, "z": 23},
    {
      "id": "B-03",
      "measurements": {
        "pressure": {"value": 0.62, "unit": "MPa"},
        "temperature": {"value": 36.8, "unit": "℃"}
      }
    }
  ]
}
```

位置使用实体所在视图的场景坐标，单位米，x 向右/东、z 向前/南；A/B 区为各自室内坐标。必须同时提供 x 和 z。模型关联的 GIS 坐标是设计定位，尚未进行现场坐标标定。接入 GPS、UWB 或摄像头定位前，应由适配器转换到对应工区的场景坐标。

接口按实体编号校验，未知编号或不完整位置会拒绝；同一批请求先完整校验，避免一半数据成功一半失败。采集时间采用后台收到请求的 UTC 时间，source 为 telemetry。需要真实数据的新鲜度时，适配器应只上报新采集的数据，不能反复回传历史缓存。温度单位 ℃、负荷 %、压力 MPa、电流 A、电压 kV、漏电 mA、速度 m/s。

设备测量对象按整条 measurements 替换；上报程序应发送该设备当前完整的测量集合。已接入接口定位的演示对象不会再接受演示轨迹启动；位置与测量来源独立保存。

演示控制：`POST /factory/demo`，参数 `{"action":"start","key":"overview"}`；key 可用 overview、vehicle、a、b，action 可用 start、stop、reset。演示轨迹是循环路线，后台统一运行。

验证包括模型/后台台账一致、区域坐标转换、接口校验、进入/离开事件、过期定位、数据持久化、演示覆盖保护、后台采样及已有功能回归。还在实际页面验证了人员 P023、车辆 E-04 的两个页面共同报警，以及服务断连后自动恢复。

本版本随项目仓库发布；运行日志、现场或演示观测数据库、密钥及本地虚拟环境不包含在代码发布中。
