# 接口文档

## 系统调用关系

```
前端 Web 看板 → 智能体(lxy) → GIS 接口(wjy) + 电气接口(lry)
```

## GIS 输出接口（wjy 负责）

### 接口1：查询危险区域

- 路径：`GET /zones`
- 调用方：智能体、前端
- 输入：无
- 输出：危险区域列表 JSON

### 接口2：人员是否闯入危险区

- 路径：`POST /check_danger`
- 调用方：智能体
- 输入：

```json
{ "person_id": "P001", "lng": 120.1235, "lat": 30.4565 }
```

- 输出：

```json
{
  "person_id": "P001",
  "inside_zone": true,
  "zone_id": "Z001",
  "zone_type": "基坑",
  "risk_level": "高",
  "alert": "人员P001进入基坑危险区"
}
```

## 电气输出接口（lry 负责）

### 接口1：查询所有电气设备风险

- 调用方：智能体、前端
- 输出：设备风险列表 JSON

### 接口2：查询单个设备详情

- 输入：`{ "device_id": "D003" }`
- 输出：单个设备 JSON

## 数学/智能体输出接口（lxy 负责）

### 接口1：综合风险查询

- 输入：`{ "query": "今天哪个区域风险最高？" }`
- 输出：综合风险评估 JSON

### 接口2：巡检路线优化

- 输入：`{ "start_point": [120.123, 30.456], "risk_zones": ["Z001", "Z002"] }`
- 输出：最优巡检路线 JSON

## 统一约定

1. 所有接口统一用 JSON 格式
2. 所有坐标统一用 [经度, 纬度]
3. 所有风险评分统一用 0-1
4. 所有接口先用模拟数据跑通，再对接真实数据
5. 接口变更必须提前在群里通知三人
