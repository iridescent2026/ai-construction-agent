# 工厂分析与作业闭环 V15

## 界面与操作

首页与 GIS 固定为铸钢总控：银灰钢框、螺钉、深色拉丝面板、金色控制元素。首页保留外观、整体 A/B 剖面和局部 A/B；GIS 仅卫星、厂区平面、三维外观，删除第四个剖面。两页底部均提供五个分析页签，详细台账可折叠。

1. **设备影响链**：选择 B-05 循环排水泵组，查询候选管廊、B-01 供电柜、Z007 作业区、当前有效区域人员与关联工单。点击高亮：首页进入对应工区并框选对象；GIS 标出有坐标的关联实体。默认连接只是演示设计，不能证明工程连接或故障传播。图节点可包含 pipe 虚拟节点和 modelGroup 模型组名称；实际实体编号、工区、类别必须与台账一致。确认连接必须提供 reference 图纸依据、reviewer 复核人，但姓名尚未鉴权。图查询双向最多三跳，不能当作电气/流体有向因果仿真。
2. **作业冲突**：填写作业计划或载入演示示例，再点击保存检查。只比较同一坐标系下的矩形范围和时间交集；展示重叠分钟、平方米与来源。完整替换前可导出备份。A、B 与 overview 坐标系分开，不能直接用相同局部坐标判断跨厂房冲突。当前不支持楼层高度、多边形、吊装动态扫掠和作业许可审批。
3. **险情回放**：后台每秒记录观测，读取历史后拖动时间轴。模型、人员位置和空间状态切到历史帧，实时轮询仍保存最新数据但不覆盖回放；返回实时恢复最新状态。醒目提示显示历史时间，分析查询/工单仍基于实时后台。每帧保留最近 20 条事件，最多 3600 帧，不是长期监控录像。人员停留依据连续有效观测估算；超过 5 秒、服务重启、来源变化不补造轨迹；过期/缺失位置单独计未知，首帧在区内不计新进入。
4. **维修闭环**：人工发起 → 指派 → 指派人开始 → 提交文字凭证（可选照片）→ 另一人复核关闭。支持退回、重开。每次操作带 expectedVersion；陈旧版本返回 409，不能覆盖其他操作。操作与触发观测留存，SQLite 提交成功才返回成功；关闭工单不会自动解除空间报警。照片只允许 PNG/JPEG/WebP ≤2 MB。姓名为自报，不能证明真实操作身份，也不替代现场验收。
5. **能耗与空转**：导入电表 kW 采样，按相邻有效采样梯形积分为 kWh；间隔超过 120 秒不补造。不同来源、不同设备、不同班次独立统计，不能跨班次缺口连接。running=false 的连续区间记待机耗能估算；运行状态缺失显示未知，不显示 0。productionDelta 是本次新增产量；未提供产量时不算单位产量能耗。待机并不自动等于浪费，仍需结合工艺和班次确认。没有电表时明确待接入，不估算节省金额。DEMO_MODE=0 拒绝演示计划和电表，按钮禁用。

## 直线测距

GIS 点击“测距：点击两点”，依次点起终点，显示标注线、米数与结果卡。示例自动选取 A/B 二维轮廓中心，当前参考布局约 41.7 m；这是中心间距，不是厂房边缘净距。适合粗看通道跨度、点位间距、隔离范围的地图尺度。卫星参考与业务点位没有现场测绘配准，结果不作为安全间距、施工放线或可行走路线；路线仍需要绕开围挡、设备等障碍物。

## API

分析服务挂在 GIS API 的 `/factory/analysis`，与 `/factory/state` 共用工厂台账。

| 方法与路径（分析前缀后） | 内容 |
| --- | --- |
| GET 空路径 | 实时观测版本、实体、台账、计划、冲突、工单统计、电表估算与录制错误 |
| GET /impact/{entityId} | 三跳关联、候选/复核依据、当前有效人员、关联工单 |
| POST /graph | 完整替换 `{nodes:[],edges:[]}`；最多 100 节点 / 300 连接 |
| POST /plans | 完整替换 `{plans:[]}`；最多 100 项，同坐标系时空检查 |
| GET /replay | 已记录帧的编号和时间 |
| GET /replay/{id} | 指定历史观测；过期或不存在返回 404 |
| GET /exposure | 连续观测停留估算、未知时长、进入次数与录制断档 |
| POST /orders | `{entityId,reason,actor}` 人工创建，保留触发观测 |
| GET /orders/{id}/image | 按需读取照片凭证；轮询摘要不重复发送图片 |
| POST /orders/{id} | `{action,expectedVersion,actor,assignee,note,image}` 状态流转 |
| POST /meters | `{readings:[]}`；最多 1000 条/批，重复编号同内容幂等，冲突整批拒绝 |

计划格式：

```json
{"plans":[{"id":"PLAN-001","title":"泵组检修","view":"b","startsAt":"2026-10-08T09:00:00+08:00","endsAt":"2026-10-08T10:00:00+08:00","center":[10,10],"size":[4,3],"kind":"检修","source":"manual"}]}
```

电表格式（observedAt 必须替换为实际采集时间，带时区，未来记录拒绝）：

```json
{"readings":[{"id":"METER-001","deviceId":"B-05","observedAt":"2026-10-07T09:00:00+08:00","powerKW":6.2,"running":true,"shift":"白班","productionDelta":null,"source":"telemetry"}]}
```

source=telemetry 表示采集方声明接口来源，不证明设备真实性。相同设备、来源、采集时刻不能换编号重复录入；最多 20000 条，达到限额拒绝导入，需人工归档。当前不提供设备协议适配器和电表累计计数差分算法。

## 存储、启动与边界

分析库在 FACTORY_DB_PATH 同目录，后缀为 `.analysis.db`。保存连接、计划、工单、电表和回放；不随源码 ZIP 打包，避免混入本机业务记录。最多 500 条本地工单，不提供企业级归档/账号管理。回放库相对较大，部署需规划磁盘与备份。

新增后端模块后需重启服务。停止原启动窗口（Ctrl+C），再运行同目录 `run_demo.py`，或工作区 `outputs/启动GIS改进版.cmd`。后者首页 `http://127.0.0.1:48080/`，GIS `http://127.0.0.1:48080/workbench.html`。保持启动窗口开启；浏览器 Ctrl+F5 刷新不等于重启后端。

当前是本机可交互原型，尚缺真实设备身份、账号角色、工程连接复核、现场坐标配准及持续真实数据。正式推广前应补账号权限/审计、项目隔离、TLS 网关、只读与写入权限分离、真实作业台账、人工签收和数据备份。照片凭证需要受控存储；不要把当前本地接口直接公开到公网。
