# V26 参赛验证与操作改进

沿用恢复后的重工业界面和原厂区轮廓。首页与 GIS 定位采用局部预览，复用实际模型或地图，返回保留原页面与列表位置；下方重复登录表单移除，全部操作使用页首会话。

连接台账新增 relationKind（power/fluid/control/spatial/other/unknown）、direction（forward/bidirectional/unknown）及 condition。旧台账默认未核验，不自动变成有向工程关系。影响查询保留三跳候选关联，另列填写方向后可达的候选；均不证明异常传播。

模型调用尝试额度存入独立数据库，所有空间共用，按 UTC 日计算；一分钟每空间六次限制仍有效，失败调用也计数。配置外部 PostgreSQL 时随该存储持久保存；本地默认 SQLite。`WORKFLOW_QUOTA_DB_PATH` 可配置，`WORKFLOW_MODEL_DAILY_LIMIT` 控制应用次数，不是供应商账单硬上限。管理员账号中心可查询额度。

正式管理员可读取并导出演示空间清单、归档过期空间或取消归档，输入明确确认文字后操作。归档释放40个空间的应用数量限制，不删除业务数据库或释放数据库容量；取消归档不延长旧凭据。归档及恢复操作留存历史。演示账号不能管理全局空间。

真人实验同时统计错误、未完成、准确率及用时，同题取第一次完成记录，禁止挑最好成绩。演示、备份导入和自动化验收不计真人成效。具体组织方法见[实验说明](prototype-experiment-v26.md)，业务审阅见[工程清单](engineering-review-v26.md)。

验证：完整后台127项通过，前端50项通过；本地浏览器已验证首页定位返回、搜索保留、手机预览、刷新、单一登录身份及待核验方向。公网发布及 GIS 预览还需随后验收，结果补在发布记录中。测试数量不包含重复运行累计。
