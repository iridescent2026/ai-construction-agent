# GIS 室外联动（V15）

以 GitHub main e1cb628 为基础的本地更新。

首页保留 A/B 工区与厂区整体剖面。按用户最新要求，GIS 删除第四个纵剖面，只提供卫星、厂区平面、三维外观。A/B 内部设备与管线请在首页查看。模型为设计示意，不是实测 BIM。

GIS 指标、地图点位和当前区域报警仅统计室外 overview，订阅同一 /factory/state。过期或断连为未知，不将告警伪造为解除。数据刷新与重载卫星影像分别提供按钮；卫星仍是有日期的历史影像。分析模块单独查询关联台账，可在平面高亮 A/B 关联位置，但不混入室外告警统计。历史回放明确显示历史时间，返回实时后恢复自动同步。

选择“室外 · 三人协同巡检”，启动 P023、P024、P021。P023 穿过土方区，P024 经过吊装区，P021 在外部通道巡查。首页与 GIS 的启动和停止控制共享后台状态。接口上报该组任一人员后，模拟停止，保护接口位置。

侧栏“数据接入与核验”支持 JSON 导入位置和设备读数。默认示例是手动测试输入，不代表真实 GPS。现场适配器仍需要提供来源、坐标转换与鉴权。

```json
{"observations":[{"id":"P023","x":-28,"z":23,"observedAt":"2026-10-07T10:00:00+08:00"}]}
```

示例时间需换成实际采集时间。带 observedAt 时保留时间戳；缺省时按服务器接收时间处理。过期观测保持未知；无时区或未来时间被拒绝；早于该实体已有接口观测的批次整体拒绝。x 向东、z 向南，单位米。地图和后台统一 reference-site 的原点、平移、缩放和旋转，尚未进行现场配准。

已移除顶部三个风格模式及选择存储，首页和 GIS 固定使用铸钢重工业样式。URL 的 theme 参数和旧浏览器风格记录不再生效。螺钉、金属边框、风险颜色保留。

真实接入环境设置 DEMO_MODE=0：工厂服务不制造新的演示采样、不允许启动轨迹；缺少采集时间为未知。现阶段仍需为写接口增加设备身份和项目权限。

启动：在 Windows 文件资源管理器中双击 outputs/启动GIS改进版.cmd。使用独立的 48080 端口，页面 http://127.0.0.1:48080/，GIS http://127.0.0.1:48080/workbench.html。如果该端口被占用，需要先停止同端口的旧演示服务。

已增加多人演示、接口时间、批次原子校验、坐标一致、真实模式、室外过滤及刷新时序测试。V15 已在 Chrome 完成两页渲染与交互验证；测试不加载外部卫星瓦片，影像是否可达取决于使用环境网络。更多分析功能见 factory-analysis-v15.md。
