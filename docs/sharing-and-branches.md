# 访问与分支说明

`http://127.0.0.1:18080/` 只供运行服务的电脑访问。别人在自己的电脑输入该地址，会访问他们自己的电脑。

## 如何让别人使用

最直接方式是让对方克隆 main 分支，安装 requirements.txt，运行 `python run_demo.py`，再打开自己电脑的 `http://127.0.0.1:8080/`。端口偏移环境变量 DEMO_PORT_OFFSET=10000 可改为 18080。

如果希望别人直接点开一个统一网址，需要另行部署。目前启动器和静态服务器仅监听回环地址，前端配置也指向回环接口，因此只替换页面 URL 或端口映射无法完成共享。GitHub 存放代码不等于部署；GitHub Pages 不能运行此项目的 Python/SQLite/OR-Tools 服务。

推荐部署架构：浏览器通过一个 HTTPS 域名访问前端和同源 API 反向代理，后端接口仅在内部网络可达，数据库使用持久化目录。部署前补齐登录、角色/项目权限、上传认证、限流、备份与日志；真实数据环境设 DEMO_MODE=0。当前来源校验不是身份认证。本次仅推送代码，没有开放端口或部署公网服务。

同一局域网也需要专门修改服务器监听地址、前端 API 地址和允许来源，并配置防火墙。不能让访问者的浏览器继续请求 127.0.0.1。请使用独立演示数据环境，不把尚无认证的接口暴露到公共网络。

## 分支分工

|分支|本次内容|
|---|---|
|main|完整集成：电气、GIS、智能体、前端、共享代码、启动器、文档和测试|
|electrical|电气安全判定、统一快照、采样保护及共享依赖|
|gis|空间规则、人员状态、轨迹模拟、3D 与重工业管理前端及共享依赖|
|math|真实路线调用、风险汇总、真实留存历史、问答修复及共享依赖|

模块分支保留各自既有的其他模块文件，不把旧文件误当最新集成版本。完整演示和全套测试使用 main。各模块分支根目录有当前启动与接口配套说明。
