# 钢制控制台与折叠布局交付

已应用方案 A 钢制设备舱样式和选定 Logo，结合全景指挥台与演示驾驶舱。

- 默认全景：紧凑指标栏、大地图、左侧导航。点击区域/设备/助手/感知展开面板，再次点击或右上角箭头收起；Esc 也能收起。
- 演示模式：右上角进入，自动切换 3D 并展开感知面板。可选择手机或摄像头模拟；不会自动开始上报。
- 图例：地图左下角常驻颜色简表，点击展开完整图例；左侧图层入口也能打开。
- 底部说明可折叠。地图点击对象仍显示详情。
- 模拟运行时保留地图上的停止入口，折叠感知面板不会让停止按钮消失。
- 采用钢灰渐变、厚钢框、螺栓角与琥珀色交互高亮。风险颜色保持原业务含义。
- 手机宽度导航横排，指标两列，抽屉下移，页面无横向溢出。

验证：7 项前端回归测试通过；浏览器检查设备抽屉、模式切换、摄像头模拟、折叠后停止、图例及 390 像素宽度。后端业务逻辑本轮未修改。
