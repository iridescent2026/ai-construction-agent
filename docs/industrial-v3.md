# 工业风工地与移动感知演示（2026-10-05）

## 本轮交付

- 深色钢蓝控制台、青绿色交互色、工程黄色点缀；统一卡片、表单、页签、边框、图例与滚动区域。
- 可旋转的工地场景：框架楼、塔吊、围挡、道路、办公板房、材料堆场、挖掘机和运输车。均为程序构建的设计示意，不能用作实测 BIM 或路线避障依据。
- 手机定位模拟：每秒合成位置并通过 POST `/simulation/motion` 上报，人员编号为 `SIM-GPS-*`。
- 摄像头模拟：合成示意画面、人员框与编号，并将同源坐标送入空间接口；人员编号为 `SIM-CAM-*`。没有运行目标检测模型，也没有访问摄像头。
- 位置存入 SQLite，沿用区域风险计算、人数统计、二维与三维展示，不是只有前端模型在动。
- 支持停止；停止后不再发起采样，在途请求可能完成，最后位置保留并在 120 秒后标未知。页面关闭停止采样，后台标签页可能被浏览器节流。
- 模拟来源分开标记，不覆盖普通真实人员；模拟编号被 telemetry 占用时拒绝写入。`DEMO_MODE=0` 禁止模拟轨迹。

## 操作

1. 启动方式与 README 相同。本次本地页面为 http://127.0.0.1:18080/ 。
2. 点击“更新演示观测”刷新原始演示人员与设备，之后可选择“手机定位模拟”，点击“开始演示”。
3. 点击“停止”，切换“摄像头识别模拟”，再开始；右侧合成画面与地图使用同一组位置。
4. 停止后人员仍保留在登记列表中；“当前有效人员”只统计未过期记录。两种模拟采用不同编号，不表示同一人员的跨源融合。
5. 3D 可拖动旋转、滚轮缩放、点击对象查看；二维和三维共享图例、图层开关与观测。

## 真实接入边界

当前交付的是可运行的合成数据联动链路，不是真实感知算法。没有申请手机位置或摄像头权限，也没有下载不明来源监控录像。

已有真实位置可以由接入程序发送到 POST `/check_danger`，JSON 为 `{"person_id":"REAL-001","lng":120.008,"lat":30.293}`；批量使用 `/check_danger_batch`。前端只读刷新会显示已上报位置，当前自动读取间隔 30 秒。此旧入口使用服务接收时间，不支持原始采集时间和精度字段，真实生产接入前仍需补充这些字段及校验。

要实现真实手机定位，仍需开发手机采集端、用户位置授权、精度展示和安全传输，并核对坐标系；现在没有手机采集页面。要实现真实视频识别，仍需视频输入、人员检测与跟踪、摄像机标定和像素到地面坐标转换；单凭一个人员框不能可靠推断工地经纬度。多人跨摄像头身份也尚未融合。

本地服务仅监听回环地址，尚无生产认证与项目权限。不能为接手机而直接把当前接口公开。后续接真实设备时应先完成认证、权限、采集时间与数据质量处理，再接入实际场景。
